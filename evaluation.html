Algorithm Overview

Core machine learning algorithms used in the project

1. K-Nearest Neighbors (KNN)

Finds similar movies based on genre similarity using cosine distance across 19 binary multi-hot genre features.

2. K-Means Clustering

Groups movies into 10 thematic clusters based on genre features, providing fast candidate filtering by archetype.

Evaluation Note: Recommendation metrics (Precision, Recall, F1) use genre-based overlap (≥0.60 Cosine similarity) as a relevance proxy rather than human ratings.
