Algorithmic Formulations

Vector space representations and optimization mechanics

1. K-Nearest Neighbors (Cosine Metric)

Each movie is encoded into a 19-dimensional binary vector where each dimension represents the presence (1) or absence (0) of a MovieLens genre category.

Cosine Distance = 1 - (u · v) / (||u|| ||v||)

Cosine distance measures the angular orientation between two genre vectors rather than Euclidean magnitude. Films with identical genre sets achieve distance 0.0 (100% similarity), while films with disjoint genre sets achieve distance 1.0 (0% similarity).

2. K-Means Clustering

K-Means partitions the 9,742 catalog films into 10 thematic archetype clusters using Lloyd's algorithm with k-means++ centroid initialization.

Inertia (Sum of Squared Distances): 8,170.51

The model clusters films into coherent cinematic groups (e.g., romantic dramas, neo-noir thrillers, family animation). Users can optionally restrict KNN searches to the query movie's cluster to guarantee genre archetype coherence.
